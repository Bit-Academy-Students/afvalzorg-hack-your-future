userstories gaan hier

wat moet er in {
de userstory zelf:
als (rol) wil ik (bepaalde actie of functionaliteit) zodat ik (een bepaald doel bereiken)
acceptatie criteria
moscow type (must have, should have, could have or wont have).
}

Als gebruiker wil ik me online kunnen aanmelden en inchecken op de locatie zodat mijn werkgever kan zien dat ik er ben en waar.
prioriteit:
Must have
acceptatie kriteria:
Er is een inlog- en uitlog pagina.
Je kan inchecken op specifieke locaties zodra je bent ingelogt.
De admin van de pagina kan zien waar en wanneer iemand is ingechecked.

Als werkgever wil ik dat voordat mijn werknemers kunnen inchecken zij een digitale veiligheidsinstructie moeten lezen en een veiligheidsfilmpje moeten bekijken en ondertekenen zodat mijn werknemers veilig kunnen werken.
prioriteit:
Must have.
acceptatie kriteria:
de werknemers moeten naar beneden scrollen en op een box drukken om verder te kunnen gaan.
de box kan niet gebruikt worden als je niet helemaal naar beneden bent gescrolled.


als werkgever wil ik dat de veiligheidsinstructie in meerdere talen aanwezig is zodat elke werknemer het kan lezen
prioriteit:
must have
acceptatie kriteria:
De veiligheidsinstructies kunnen in minimaal drie talen worden laten zien nederlands, engels en duits..
je kan bij een lijst kijken waar  op staat of er opeen bepaalde plek gewerkt wordt
je kan naar een pagina gaan waarin staat welke weg ingebruik is en welke niet.
je moet voor deze functies ingelogt zijn.


Als werkgever wil ik de veiligheidsinstructie kunnen veranderen zodat het altijd up-to-date is
prioriteit:
Should have
acceptatie kriteria:
Er is een veiligheidsinstructie edit pagina waar je de veiligheidsinstructies kan veranderen.
Je kunt alleen bij deze pagina’s als je ingelogd bent als een werkgever/admin


als werkgever wil ik dat er een overzichtspagina is waar ik kan zien wie er op welke locatie is
prioriteit:
Should have
acceptatie kriteria:
Er is een admin pagina die alleen de werkgever kan zien waarin staat wie op welke locatie is en er werkt.
Je kan zien hoelaat en hoe laatiemand op een locatie is.


Als werkgever wil ik dat de veiligheids instructies per locatie verschillen zodat de bijpassende instructies bij de goede locatie zitten
prioriteit:
Should have
acceptatie kriteria:
De instructies zijn per locatie toegankelijk
